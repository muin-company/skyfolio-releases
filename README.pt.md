# Skyfolio — releases e feedback

**Skyfolio** mantém suas astrofotos no seu próprio dispositivo: galeria, diário, carta celeste e catálogo, sem conta, sem anúncios e sem servidor.
Site: https://skyfolio.space · Demo: https://skyfolio.space/demo/ · Suporte: skyfolio@muin.company

## Baixar
- **Mac** (Apple silicon): `.dmg` da release mais recente, assinado e notarizado
- **Windows**: instalador `.exe` (ainda sem assinatura — se o SmartScreen avisar, “Mais informações” → “Executar assim mesmo”)
- **Linux**: `.AppImage` ou `.deb`
- **Android**: `.apk` até a página do Google Play abrir
- **iPhone / iPad**: App Store (em preparação)

→ https://github.com/muin-company/skyfolio-releases/releases/latest

## Feedback
- **Relato de bug / pedido**: abra uma issue com um dos formulários — https://github.com/muin-company/skyfolio-releases/issues/new/choose
- **E-mail** (sem conta no GitHub ou em particular): skyfolio@muin.company — informe a versão do app e o seu dispositivo.
- Não anexe fotos originais nem arquivos com dados de localização. Uma captura de tela basta.
