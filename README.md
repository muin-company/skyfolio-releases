# Skyfolio — releases & feedback

**Skyfolio** keeps your astrophotos on your own device: gallery, journal, sky chart and catalog, with no account, no ads and no server.
Website: https://skyfolio.space · Demo: https://skyfolio.space/demo/ · Support: skyfolio@muin.company

## Download
- **Mac** (Apple silicon): `.dmg` from the latest release, signed and notarized
- **Windows**: installer `.exe` (not code-signed yet — if SmartScreen warns, choose More info → Run anyway)
- **Linux**: `.AppImage` or `.deb`
- **Android**: `.apk` until the Google Play listing opens
- **iPhone / iPad**: App Store (in preparation)

→ https://github.com/muin-company/skyfolio-releases/releases/latest

## Feedback
- **Bug report / feature request**: open an issue with one of the forms — https://github.com/muin-company/skyfolio-releases/issues/new/choose
- **Email** (no GitHub account, or private): skyfolio@muin.company — please include the app version and your device.
- Please do not attach original photos or anything with location data. A screenshot of the screen is enough.
