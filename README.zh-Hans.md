# Skyfolio — 发布与反馈

**Skyfolio** 把天文照片只保存在你自己的设备上：图库、观测日志、星图和图鉴，没有账号、广告和服务器。
网站: https://skyfolio.space · 演示: https://skyfolio.space/demo/ · 支持: skyfolio@muin.company

## 下载
- **Mac**（Apple 芯片）: 最新发布中的 `.dmg`，已签名并公证
- **Windows**: 安装程序 `.exe`（尚未签名 — 若 SmartScreen 警告，点"更多信息"→"仍要运行"）
- **Linux**: `.AppImage` 或 `.deb`
- **Android**: 在上架 Google Play 之前使用 `.apk`
- **iPhone / iPad**: App Store（准备中）

→ https://github.com/muin-company/skyfolio-releases/releases/latest

## 反馈
- **错误报告 · 功能请求**: 选择表单提交 Issue — https://github.com/muin-company/skyfolio-releases/issues/new/choose
- **邮件**（没有 GitHub 账号或希望私下反馈）: skyfolio@muin.company — 请注明应用版本和设备。
- 请不要上传照片原文件或含位置信息的文件。屏幕截图即可。
