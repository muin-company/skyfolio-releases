# Skyfolio — release e feedback

**Skyfolio** tiene le tue astrofoto sul tuo dispositivo: galleria, diario, carta del cielo e catalogo, senza account, pubblicità o server.
Sito: https://skyfolio.space · Demo: https://skyfolio.space/demo/ · Supporto: skyfolio@muin.company

## Scarica
- **Mac** (Apple Silicon): `.dmg` dall’ultima release, firmato e notarizzato
- **Windows**: installer `.exe`, `x64` per la maggior parte dei PC, `arm64` per Windows on ARM (non ancora firmato — se SmartScreen avvisa, «Ulteriori informazioni» → «Esegui comunque»)
- **Linux**: `.AppImage` o `.deb`, x64 e ARM64
- **Android**: test chiuso su Google Play (https://play.google.com/apps/testing/company.muin.skyfolio); l’e-mail dell’account Google deve essere nell’elenco dei tester: scrivi a skyfolio@muin.company
- **iPhone / iPad**: App Store (in preparazione)

→ https://github.com/muin-company/skyfolio-releases/releases/latest

Le app per Mac e Windows e l’AppImage per Linux ti avvisano quando esce una nuova versione.

Per ricavare foto dagli scatti grezzi serve Siril (gratuito) o PixInsight sul computer. L’Aiuto dell’app dice cosa installare.

## Feedback
- **Segnalazione bug / richiesta**: apri una issue con uno dei moduli — https://github.com/muin-company/skyfolio-releases/issues/new/choose
- **Email** (senza account GitHub o in privato): skyfolio@muin.company — indica la versione dell’app e il dispositivo.
- Non allegare foto originali o file con dati di posizione. Basta uno screenshot.
