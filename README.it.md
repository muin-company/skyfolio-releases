# Skyfolio — release e feedback

**Skyfolio** tiene le tue astrofoto sul tuo dispositivo: galleria, diario, carta del cielo e catalogo, senza account, pubblicità o server.
Sito: https://skyfolio.space · Demo: https://skyfolio.space/demo/ · Supporto: skyfolio@muin.company

## Scarica
- **Mac** (Apple Silicon): `.dmg` dall’ultima release, firmato e notarizzato
- **Windows**: installer `.exe` (non ancora firmato — se SmartScreen avvisa, «Ulteriori informazioni» → «Esegui comunque»)
- **Linux**: `.AppImage` o `.deb`
- **Android**: `.apk` finché la scheda Google Play non è aperta
- **iPhone / iPad**: App Store (in preparazione)
